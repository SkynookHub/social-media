Términos y Condiciones de Comisión

⏱️ Pago y Tiempo

  • Anticipo: Se requiere un 50% del pago para iniciar el trabajo y asegurar tu cupo.
  • Tiempos de entrega: El tiempo estimado es de 1 a 2 semanas. El tiempo final podrá variar según la complejidad del dibujo o los tiempos de respuesta del cliente durante las revisiones.

✏️ Proceso de Revisión

  • Fase de Boceto: Es el momento ideal para realizar cambios estructurales (pose, ropa, composición). Una vez aprobado el boceto, no habrá más cambios de dibujo.
  • Fase de Color: En esta etapa solo se permiten ajustes de paleta cromática o iluminación. No se realizarán modificaciones a la estructura o línea.

©️ Uso y Derechos

  • Uso Personal: El precio exhibido es exclusivamente para uso privado (redes sociales, iconos, regalos). No está permitida su reventa o uso en productos.
  • Uso Comercial: Si deseas utilizar la obra para mercancía, publicidad o streaming (Twitch/YouTube/Kick), debes indicarlo al inicio. Esto requiere un contrato distinto y tiene un costo adicional.
  • Derechos del Artista: Me reservo el derecho de publicar el proceso o el resultado final en mis redes sociales (Instagram, Cara, Twitch, X, etc.) para mi portafolio. Si el cliente desea privacidad absoluta, se aplicará un costo adicional.
